THE SHORT-MONTH PROMISE

A 31st never goes missing.

Monthly reminders use the last available day, then return to your original date. February 29 yearly reminders use February 28 in other years. Months mean calendar months, not 30-day blocks.

JAN31→FEB28→MAR31

Times follow the PC’s local clock. A time skipped by the spring clock change moves to the first valid minute. The autumn repeated hour produces one pending occurrence. Changing timezones keeps the chosen wall-clock time. If you snooze past another repeat, the task stays one pending reminder; completing it advances to the next future occurrence.

YOUR FILM GETS TO FINISH

Full-screen means: we wait.

A full-screen video or app keeps a due reminder quietly behind it. Switching to another app does not release it. QuestBell waits for that same window to leave full-screen mode or close. Another full-screen app keeps the wait going. The chime plays only when the reminder comes forward.

☾

PC asleep or off? Missed reminders wait for your return. Repeated missed occurrences of one task become one pending reminder. Several different tasks appear oldest first, one at a time, with a waiting count. QuestBell must be running; it does not wake a sleeping or powered-off PC.

Your tray companion

Closing the main window keeps QuestBell running. Double-click its bell icon to reopen it. Right-click for a new reminder, the next scheduled time, Return to reminder, Pause, the guide, or Exit.

Pause for 30 minutes, an hour, or until tomorrow at 09:00. Tasks stay pending; Resume releases the queue. Exit stops delivery until the app runs again.

Comfort controls

  • Choose English or Greek. Custom titles and phrases keep your wording.
  • Use the primary monitor, all monitors, or a specific display. Acting on one closes the others.
  • Mute globally or for individual tasks. Optional follow-up chimes are off by default.
  • Reduce motion, change Escape’s snooze duration, and adjust the website-return delay.

Your own little shortcuts.

Open Settings → Your quick choices → Customize quick reminders & times. Add a reminder title, Personal or Work mode, an artwork family and a default repeat. Your custom reminders appear in step 1 of the wizard. Removing a shortcut keeps any real reminders you already created.

Add time buttons for an exact 24-hour time, a number of days from today, or a relative delay in minutes, hours, days, weeks or months. Tap × to remove a button, including defaults. Date buttons keep the entered time; clock buttons keep the selected date. Clock times and relative delays appear under More timing choices. Restore default time buttons brings back Today, Tomorrow, Next week and 09:00, 12:00, 18:00, 20:00.

Changes save immediately on this PC and are included in backups. Cloud reminder sync keeps these choices local. You can keep up to 100 custom reminders and 30 time buttons. The normal scheduling fields work even if all quick time buttons are removed.

☁

A shared home. Only if you want one.

Cloud sync and automatic backups are both off by default. Open Settings → Cloud sync & backups. Choose a private folder managed by your cloud desktop app and apply either or both switches. QuestBell creates a QuestBell Cloud subfolder.

On each other PC, install QuestBell 1.5.0 or later, wait for the cloud folder to download, then select that same QuestBell Cloud folder. Keep it available offline: in OneDrive, use Always keep on this device. Your cloud desktop client handles sign-in and transfers.

Reminders, Done, Snooze, history and custom phrases travel between PCs. Language, monitor, startup, mute and pause preferences remain local. Checks run every 30 seconds while QuestBell runs. Folder updated means local exchange succeeded; check your cloud client for upload confirmation. Offline PCs may both notify until changes arrive.

Automatic backups keep the latest 30 changed snapshots per PC. Restore a backup asks before replacing data, keeps a recovery copy and turns both cloud switches off for review. Reconnecting merges the restored changes. Open recovery copies also provides local copies made before incoming changes.

Simultaneous edits to the same reminder choose one whole version consistently. Previous local data is kept in recovery copies. Files are readable, so use a private folder. Turning off leaves existing cloud files and local reminders in place.

◇

Your data belongs here. With you.

No cloud account, analytics, or network service is needed. Data is stored in %LOCALAPPDATA%\QuestBell\questbell.json. Export a JSON backup from Settings. Import replaces current tasks, history, phrases and settings after confirmation, keeping a before-import copy. Backups are readable files, not encrypted.

Writes are atomic and keep a previous backup. A damaged file is preserved before attempting recovery. If both copies are unreadable, the app stops and tells you where to find the data rather than starting over silently.

THE PRACTICAL BITS

A few things worth knowing.

Setup cannot create a desktop or Start-menu shortcut. What happens?

QuestBell still installs when an optional shortcut or Windows setting is blocked. You can open the app directly from %LOCALAPPDATA%\Programs\QuestBell\QuestBell.exe. View setup details shows the full explanation; the log is also saved to %TEMP%\QuestBell-setup.log. Essential file or data errors still stop installation and show the actual error. Run the latest installer over a previous failed attempt; existing reminder data is kept.

How do GitHub updates work?

Open Settings → App updates → Check for updates. Click Update now to download the stable GitHub installer directly. QuestBell verifies its published size and SHA-256 checksum before installing, then closes briefly and reopens with your reminders, language and startup choice preserved. Cancel download is available before installation. Daily automatic checks are optional; installation starts only on your click. No reminder data is sent. Release notes remain available on GitHub.

How do I install it?

Run QuestBell-Setup-1.5.0.exe and choose Install. It installs for your Windows user, includes the .NET runtime, creates Start-menu shortcuts, and provides an uninstaller. No administrator account or separate runtime download is needed. Requires 64-bit Windows 10 22H2 or Windows 11. The first build is unsigned, so Windows may show a publisher/SmartScreen warning; only run the installer you received from your trusted project folder.

Why is my reminder waiting in the background?

Check for a full-screen app on any monitor, including one you switched away from. That app must leave full-screen mode or close. Check the tray for Pause, Windows’ hidden tray icons, and the reminder’s enabled state. Locked sessions wait until unlock. Some exclusive games and secure Windows screens behave differently; the app does not bypass Windows security or game controls.

What happens if I click Done by mistake?

Use Undo in the main window or History. Undo is available while that task has not been edited or advanced again; it will not overwrite newer changes. A restored overdue task can appear again immediately.

Does a due date automatically create another reminder?

No. Your reminder time controls when the screen appears. A separate due date is a visible deadline and helps group overdue tasks. Use recurrence or snooze for another scheduled appearance. Optional follow-up chimes repeat at their chosen interval while the reminder is visible; they never create duplicate tasks.

How do I uninstall or move to another PC?

Export a backup first. Uninstall from Windows Settings → Apps or the Start-menu shortcut. The uninstaller keeps your reminder data. To move PCs, install QuestBell on the other PC and import your backup. To erase saved tasks, exit the app and remove %LOCALAPPDATA%\QuestBell after keeping any backup you need.
